## 🎮 About the Game

**The Lord of the Bricks** is a brick-breaker arcade game inspired by the legendary **Arkanoid**, infused with an artistic style inspired by **The Lord of the Rings** universe.

You control a paddle, bounce a ball, and smash through waves of Orc blocks until nothing remains but rubble.

Simple mechanics, satisfying destruction, and a fantasy twist.

---

## 🕹️ Gameplay

- Move the paddle using the **Left ⬅️** and **Right ➡️ arrow keys**
- Bounce the ball to hit **Orc blocks**
- Each block has **health** and collapses after enough hits
- Destroy all blocks to **complete the level**

---

## 🧙 Project Background

This project was originally built in **7 days** as a showcase of our newly acquired skills after just **2 weeks of learning Java**.

At the time:
- The game was exported as a **`.jar` file**
- Built using **Apache Ant**
- Focused on core gameplay and fundamentals

As we continued learning, we revisited and improved the project:
- 🔁 Replaced **Apache Ant** with **Maven**
- 🧠 Refactored code as our understanding grew
- 🛠️ Added improvements and fixes over time

The game is **still actively being developed**.  
For upcoming features, known issues, and ideas, check the **Issues** tab.
